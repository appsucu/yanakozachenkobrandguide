# Yana Kozachenko — Visual Guide

Статичний сайт на HTML, CSS і JavaScript. Збирання та залежності npm не використовуються; всі файли відформатовані та розбиті на логічні модулі для зручного пошуку й редагування.

## Запуск у VS Code (з миттєвим оновленням)

1. Відкрийте папку проєкту у VS Code.
2. Відкрийте термінал VS Code та виконайте:

```bash
python3 dev.py
```

Якщо команда `python3` недоступна (наприклад, у Windows), використайте `python dev.py` або `py dev.py`.
3. Відкрийте http://localhost:8000.

Після запуску `dev.py` усі зміни у файлах `dist/` відображатимуться автоматично без ручного оновлення сторінки:
- зміни в CSS (`dist/css/*.css`) підтягуються миттєво без перезавантаження сторінки;
- зміни в HTML (`dist/index.html`) та JS (`dist/js/*.js`) автоматично перезавантажують сторінку зі збереженням позиції прокрутки.

Для зупинки натисніть `Ctrl+C` у терміналі.

> Звичайний статичний запуск без автооновлення: `python3 -m http.server 8000 --directory dist`.

## Структура файлів та де що редагувати

### 1. Тексти та структура сторінки
- **`dist/index.html`** — відформатована розмітка всіх секцій із коментарями:
  - Шапка (`<header>`) та Головний екран (`#guide`)
  - Навігація (`.section-nav`)
  - `01` Інтерактивна майстерня (`#studio`)
  - `02` Палітра бренду (`#palette`)
  - `03` Типографіка (`#type`)
  - `04` Графічні елементи та Highlights (`#elements`)
  - `05` Instagram-композиція / сітка 3 × 3 (`#feed`) — тут знаходяться плитки сітки та примітка *«Демонстраційна сітка 3 × 3. Фотографії взято з PDF, це не підключена Instagram-сторінка.»*
  - `06` Правила перед публікацією (`#rules`)
  - Підвал (`<footer>`)

### 2. Дані та інтерактивність (`dist/js/`)
- **`dist/js/data.js`** — усі дані, що генеруються динамічно:
  - `palette` — кольори бренду, їхні HEX-коди та описи (Розділ 02)
  - `presets` — готові колірні сценарії майстерні (Розділ 01)
  - `colorControlLabels` — підписи полів вибору кольорів
  - `icons` — іконки, назви та SVG для Instagram Highlights (Розділ 04)
- **`dist/js/studio.js`** — логіка роботи інтерактивної майстерні кольорів (прев’ю 4:5 / 9:16, перевірка контрасту, збереження в `localStorage`).
- **`dist/js/render.js`** — генерація карток палітри та кружечків Highlights.
- **`dist/js/utils.js`** — допоміжні функції (`toast`, копіювання в буфер обміну `copy`, формула яскравості `lum`).
- **`dist/app.js`** — головна точка входу, яка запускає модулі.

### 3. Стилі (`dist/css/`)
- **`dist/css/base.css`** — шрифти (`@font-face`), базові стилі, шапка, навігація, підвал, спливаючі підказки.
- **`dist/css/hero.css`** — стилі першого екрана (`#guide`).
- **`dist/css/studio.css`** — стилі інтерактивної майстерні (`#studio`).
- **`dist/css/palette.css`** — стилі карток палітри (`#palette`).
- **`dist/css/typography.css`** — стилі секції типографіки (`#type`).
- **`dist/css/elements.css`** — стилі графічних символів та Highlights (`#elements`).
- **`dist/css/feed.css`** — стилі сітки Instagram 3 × 3 (`#feed`).
- **`dist/css/rules.css`** — стилі секції правил (`#rules`).
- **`dist/css/responsive.css`** — адаптивна верстка для планшетів та телефонів (`@media`).
- **`dist/style.css`** — об’єднувальний файл стилів (`@import`).

### 4. Ресурси
- **`dist/assets/`** — фотографії (`.webp`), шрифти (`.ttf`) та оригінальний борд (`brandboard.png`).
